# Generated Visual Assets

Esta carpeta es para assets generados con herramientas de IA visual.

## Cómo agregar assets

1. Genera las imágenes usando los prompts en `/docs/ai-visual-prompts.md`
2. Optimiza a WebP (calidad 85, max 200KB para hero)
3. Coloca en la subcarpeta correcta:
   - `hero/` — fondos y elementos del header
   - `share/` — banners para redes sociales
   - `generated/` — elementos decorativos generales
